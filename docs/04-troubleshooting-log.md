# 04. Troubleshooting Log & Root-Cause Resolutions

| # | Node / Component | Symptom / Error Message | Root Cause | Resolution |
| :--- | :--- | :--- | :--- | :--- |
| 1 | `microk8sMaster` (`kine` / `kubelite`) | API server freezes and `dqlite` timeouts under load | Slow random 4K write IOPS on an older microSD card starved `kine` datastore commits | Rebuilt Pi 5 onto Ubuntu 24.04 LTS using a V30 A2-rated microSD card |
| 2 | `ubuntu-Host` (`apt` / Docker) | Missing `docker-model-plugin` & `containerd`/`docker.io` dependency conflicts | Deprecated Ubuntu Focal repository metadata and mismatched upstream Docker packages | Cleaned stale repo entries without re-flashing, applied package holds, and verified daemon via `hello-world` |
| 3 | `ubuntu-Host` (Grafana URL) | `http://192.168.2.176:30678/` timed out from workstation | Port `30678` was a legacy Kubernetes NodePort; Docker Compose binds directly to host port `3000` | Verified `ss -tulpn`, `ufw`/`iptables`, and `Test-NetConnection`, then migrated to `http://192.168.2.176:3000` |
| 4 | `ubuntu-Host` (`grafana-sandbox`) | UI hanging with `database is locked (5) (SQLITE_BUSY)` | Concurrent writes from `ngalert.scheduler` and `concurrent-job-driver` locked `grafana.db` under SQLite's rollback journal | Enabled `GF_DATABASE_WAL=true` and `GF_DATABASE_BUSY_TIMEOUT=10000` in `docker-compose.yml` |
| 5 | `ubuntu-Host` (`gops` user) | `sudo ufw status` failed: `gops is not in the sudoers file` | `gops` was intentionally provisioned as a least-privilege operator without root privileges | Executed host firewall checks via `ubuntu` admin account; kept Compose ops under `gops` |
| 6 | `ubuntu-Host` (Grafana logs) | `unlinkat .../elasticsearch/README.md: permission denied` | Background plugin auto-updater attempted to overwrite a read-only bundled plugin | Confirmed non-blocking (`All modules healthy`); optionally silenced via `GF_PLUGINS_PLUGIN_ADMIN_ENABLED=false` |
| 7 | `ubuntu-Host` (Infinity Plugin) | URL colon-parsing error and blank chart on Open-Meteo API | Query parameters placed in the wrong editor field and dashboard time range mismatched hourly forecast window | Moved query string into the Infinity URL parameters editor and adjusted dashboard time-range zoom |
| 8 | `pizero-pihole` (`pihole-exporter`) | 404 download error followed by binary execution failure | Downloaded wrong release asset / ARMv7/ARM64 binary incompatible with Pi Zero W (`armv6l`) | Downloaded the `linux_armv6` binary and applied `chmod +x` |
| 9 | `ubuntu-Host` (Git CLI) | `git init -b main` failed (`unknown switch b`) & `git branch -M main` failed (`refname not found`) | Pre-2.28 Git release does not support `-b` or branch rename prior to root commit | Committed initial files first, then ran `git branch -M main` |
| 10 | `ubuntu-Host` (GitHub Push) | `Password authentication is not supported for Git operations` | GitHub accounts with 2FA reject account passwords over HTTPS | Switched authentication to SSH key / Fine-Grained Personal Access Token |
